Lv 1 Q1. 比較演算子


                        10 > 5

⬇️ 下へ進んで答えを確認

A1. True

解説：

「10 は 5 より大きい」という条件なので、結果は真 (True) になります。
※Pythonでは真偽値の頭文字は大文字になります。

Lv 1 Q2. 型の違う比較 


                        10 == "10"

⬇️ 下へ進んで答えを確認

A2. False

解説：

数値の 10 と、文字列の "10" はデータ型が異なります。
JavaScript等では自動変換されてTrueになることがありますが、Pythonは型に対して厳格なので False になります。

Lv 2 Q3. 論理積 (and)の基本 


                        a = (10 == 10)
                        b = (5 > 10)
                        a and b

⬇️ 下へ進んで答えを確認

A3. False

解説：

a は True、b は False になります。
and（かつ）は、左右の条件が両方とも True の時のみ True になります。変数 b が False なので全体の結果は False です。

Lv 2 Q4. andを使った条件 


                        x = 10
                        x > 5 and x < 20

⬇️ 下へ進んで答えを確認

A4. True

解説：

and は左右の条件が両方とも True の時に True になります。
x > 5 は True、x < 20 も True なので、全体として True になります。

Lv 2 Q5. 比較の連続 (Python特有) 


                        x = 10
                        5 < x < 20

⬇️ 下へ進んで答えを確認

A5. True

解説：

Pythonの便利な機能で、比較演算子をつなげて書くことができます。
これは前の問題の 5 < x and x < 20 と全く同じ意味になり、よりシンプルに記述できます。

Lv 2 Q6. 論理和 (or)


                        (3 > 5) or (10 == 10)

⬇️ 下へ進んで答えを確認

A6. True

解説：

or（または）は、左右の条件のどちらか一方でも True であれば全体が True になります。
左側は False ですが、右側の 10 == 10 が True なので全体は True になります。

Lv 3 Q7. 複合問題 1


                        (5 > 3) and (10 < 5)

⬇️ 下へ進んで答えを確認

A7. False

解説：

1. (5 > 3) は True
2. (10 < 5) は False
3. つまり True and False となるため、最終結果は False になります。

Lv 3 Q8. 複合問題 2


                        not (10 >= 10)

⬇️ 下へ進んで答えを確認

A8. False

解説：

1. (10 >= 10) は「10は10以上」なので True です。
2. not は結果を反転させる「否定 (NOT)」です。
3. not (True) となるため、最終結果は False になります。

Lv 4 Q9. 優先順位のワナ 


                        (1 > 2) or (3 == 3) and (5 < 0)

⬇️ 下へ進んで答えを確認

A9. False

解説：

プログラミングにおいて、and は or よりも優先して計算されるというルールがあります。

1. 先に右側の (3 == 3) and (5 < 0) （つまり True and False）が計算され、False になります。
2. その後、残った (1 > 2) or False （つまり False or False）が計算されるため、結果は False です。

Lv 4 Q10. ややこしい複合 


                        (1 == 1) or not (3 == 3)

⬇️ 下へ進んで答えを確認

A10. True

解説：

1. 左側 (1 == 1) は True。
2. 右側 (3 == 3) は True。それに not が付いているので False になります。
3. つまり True or False となるため、どちらかがTrueなので全体は True になります。

Lv 5 Q11. ボス問題


                        a = (1 == 1)
                        b = (1 == 2)
                        not (a or b) == (not a and not b)

⬇️ 下へ進んで答えを確認

A11. True

解説：（ド・モルガンの法則）

【左辺】 aはTrue、bはFalseなので (a or b) は True。それを否定(not)するので False。
【右辺】 not a は False。not b は True。つまり False and True なので False。
左辺(False)と右辺(False)が等しい(==)ので、結果は True になります。
