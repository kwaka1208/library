Lv 1 Q1. 比較演算子（>）


10 > 5

⬇️ 下へ進んで答えを確認

A1. True

解説：

「10 は 5 より大きい」という条件なので、結果は真 (True) になります。

Lv 1 Q2. 比較演算子（==）と型 


10 == "10"

⬇️ 下へ進んで答えを確認

A2. False

解説：

数値の 10 と、文字列の "10" はデータ型が異なります。
JavaScript等では自動変換されてTrueになることがありますが、Pythonは型に対して厳格なので False になります。

Lv 1 Q3. 比較演算子（!=） 


5 != 10

⬇️ 下へ進んで答えを確認

A3. True

解説：

!= は「等しくない」を意味する演算子です。
5 と 10 は異なる値なので、5 != 10 は True になります。

Lv 1 Q4. 比較演算子（>=） 


10 >= 10

⬇️ 下へ進んで答えを確認

A4. True

解説：

>= は「以上（より大きいか等しい）」を意味します。
10 は 10 と等しいので、10 >= 10 は True になります。>（より大きい）とは違い、等しい場合も True になる点に注意しましょう。

Lv 2 Q5. 否定演算子 not の基本 


not False

⬇️ 下へ進んで答えを確認

A5. True

解説：

not は「否定」を表す演算子で、True を False に、False を True に反転させます。
not False は False の逆なので True になります。

Lv 2 Q6. 否定演算子 not と比較

⬇️ 下へ進んで答えを確認

A6. True

解説：

1. まず (3 > 5) を評価します。3 は 5 より小さいので False。
2. not False は反転されて True になります。

Lv 2 Q7. 論理積 and の基本 


a = (10 == 10)
b = (5 > 10)
a and b

⬇️ 下へ進んで答えを確認

A7. False

解説：

a は True、b は False になります。
and（かつ）は、左右の条件が両方とも True の時のみ True になります。変数 b が False なので全体の結果は False です。

Lv 2 Q8. 論理積 and の応用

⬇️ 下へ進んで答えを確認

A8. True

解説：

and は左右の条件が両方とも True の時に True になります。
x > 5 は True、x < 20 も True なので、全体として True になります。

Lv 2 Q9. 比較の連鎖（Python特有）

Lv 2 Q10. 論理和 (or)


(3 > 5) or (10 == 10)

⬇️ 下へ進んで答えを確認

A10. True

解説：

or（または）は、左右の条件のどちらか一方でも True であれば全体が True になります。
左側は False ですが、右側の 10 == 10 が True なので全体は True になります。

Lv 2 Q11. 論理積 (and)


(5 > 3) and (10 < 5)

⬇️ 下へ進んで答えを確認

A11. False

解説：

1. (5 > 3) は True
2. (10 < 5) は False
3. つまり True and False となるため、最終結果は False になります。

Lv 3 Q12. not と複合条件


not (10 >= 10)

⬇️ 下へ進んで答えを確認

A12. False

解説：

1. (10 >= 10) は「10は10以上」なので True です。
2. not は結果を反転させる「否定 (NOT)」です。
3. not (True) となるため、最終結果は False になります。

Lv 3 Q13. and の連続（3条件）


(1 < 2) and (2 < 3) and (3 < 1)
💡 ヒント： and はすべての条件が True のときだけ True になります。3つの条件をひとつずつ確認してみましょう。

⬇️ 下へ進んで答えを確認

A13. False

解説：

1. (1 < 2) は True
2. (2 < 3) は True
3. (3 < 1) は False
4. and は1つでも False があれば全体が False になります。3番目の条件が False なので結果は False です。

Lv 3 Q14. 変数と複合条件

x > 5 and x < 10 and x != 9

A14. True

3つすべてが True なので全体も True になります。

Lv 4 Q15. 優先順位のワナ（and と or） 


(1 > 2) or (3 == 3) and (5 < 0)
💡 ヒント： and と or が混在しています。計算の優先順位は and の方が or より高くなります（掛け算と足し算の関係に似ています）。

⬇️ 下へ進んで答えを確認

A15. False

解説：

プログラミングにおいて、and は or よりも優先して計算されるというルールがあります。

1. 先に右側の (3 == 3) and (5 < 0) （つまり True and False）が計算され、False になります。
2. その後、残った (1 > 2) or False （つまり False or False）が計算されるため、結果は False です。

Lv 4 Q16. 優先順位のワナ（not と or） 


(1 == 1) or not (3 == 3)
💡 ヒント： not は直後の式だけに適用されます。not (3 == 3) の部分を先に計算してみましょう。

⬇️ 下へ進んで答えを確認

A16. True

解説：

1. 左側 (1 == 1) は True。
2. 右側 (3 == 3) は True。それに not が付いているので False になります。
3. つまり True or False となるため、どちらかがTrueなので全体は True になります。

Lv 4 Q17. 優先順位のワナ（not と and） 


not (3 > 5) and (10 == 10)
💡 ヒント： 優先順位は高い順に not → and → or です。まず not (3 > 5) を評価してから and で結合します。

⬇️ 下へ進んで答えを確認

A17. True

解説：

1. not は最も優先順位が高いため、まず not (3 > 5) を計算します。
  → (3 > 5) は False、not False は True。
2. 次に True and (10 == 10) を計算します。
  → (10 == 10) は True、True and True は True。

Lv 5 Q18. ボス問題 1


a = (1 == 1)
b = (1 == 2)
not (a or b) == (not a and not b)
💡 ヒント： まず a と b の値を確認してから、左辺 not (a or b) と右辺 (not a and not b) をそれぞれ別々に計算してみましょう。これはド・モルガンの法則に関係しています。

⬇️ 下へ進んで答えを確認

A18. True

解説：（ド・モルガンの法則）

【左辺】 aはTrue、bはFalseなので (a or b) は True。それを否定(not)するので False。
【右辺】 not a は False。not b は True。つまり False and True なので False。
左辺(False)と右辺(False)が等しい(==)ので、結果は True になります。

Lv 5 Q19. ボス問題 2


a = True
b = False
(a or b) and not (a and b)
💡 ヒント： カッコの中を先に評価します。not は直後の (a and b) 全体に適用されます。これは「どちらか一方だけが True」のとき True になるパターンです（排他的論理和）。

⬇️ 下へ進んで答えを確認

A19. True

解説：（排他的論理和 XOR 的パターン）

a = True、b = False を代入します。

1. 左側 (a or b) = (True or False) = True
2. 右側 not (a and b) = not (True and False) = not False = True
3. True and True なので全体は True。

このパターンは「a と b のどちらか一方だけが True のとき True」になります（XOR）。両方 True や両方 False だと False になります。
